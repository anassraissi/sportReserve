# sportResrve

Plateforme moderne de réservation de ressources sportives.

## Démarrage rapide

```sh
npm i
npm run dev
```

## Scripts utiles

- `npm run dev` : démarre le front-end
- `npm run dev:all` : démarre front-end + serveur
- `npm run build` : build de production

## Tech stack

- Vite
- React + TypeScript
- Tailwind CSS + shadcn/ui
